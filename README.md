# 開放教案與教學資源庫 (Open Lesson Plans)

歡迎造訪 **開放教案與教學資源庫**！本專案旨在系統化整理並公開分享國中小各領域的創新教學設計、學習單與教材資源，供教育工作者與自學者自由參考與交流。

🌐 **線上公開網頁**：[https://ho-yu-chiao.github.io/lesson-plans/](https://ho-yu-chiao.github.io/lesson-plans/)

---

## 📚 教案架構與分類

本專案收錄之教案依照 108 課綱核心素養設計，主要涵蓋領域：

1. **科技領域（運算思維與演算法）**
   - [01-運算思維與演算法入門](./plans/01-運算思維與演算法入門.md)
   - 包含日常問題拆解、流程圖設計、排序與搜尋基礎教學。
2. **語文領域（閱讀教學與策略）**
   - [02-科普文本閱讀策略與理解評量](./plans/02-閱讀教學-科普文本閱讀策略.md)
   - 包含閱讀理解策略（預測、提問、摘要）、圖表解讀與探究學習單。
3. **自然科學與生活科技（電學探究）**
   - [03-生活科技與基礎電學探究](./plans/03-生活科技與基礎電學探究.md)
   - 包含電路串並聯原理、動手實作實驗與日常用電安全。

## 🚀 如何使用與部署

1. **線上瀏覽**：直接點擊 [GitHub Pages 網站](https://ho-yu-chiao.github.io/lesson-plans/)，即可依領域篩選並預覽教案內容。
2. **本機預覽**：直接以瀏覽器開啟專案根目錄的 `index.html`。
3. **開工 / 收工**：配合 AntiGravity，於對話輸入「開工」或「收工」即可自動執行狀態檢查與同步。
